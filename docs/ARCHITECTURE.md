# مستند معماری عمیق اکوسیستم ONSOUR

## ۱. مبانی نظری و مدل Tanh-Brain
اکوسیستم ONSOUR بر پایه نظریه **انتقال فاز تعاملی یکپارچه (UIPT)** و هسته محاسباتی **Tanh-Brain** استوار است. این معماری الهام‌گرفته از فیزیک آماری، پتانسیل لاندائو-گینزبورگ و پدیده‌های شکست تقارن خودبه‌خودی است.

هدف اصلی این مدل، فراهم‌کردن یک ساختار واکنش‌گر، بلادرنگ و کم‌مصرف برای عامل‌های هوشمند است که بدون وابستگی به کتابخانه‌های سنگین هوش مصنوعی، بتوانند در سطح لبه (Edge) تصمیم‌گیری کنند.

## ۲. فرمولاسیون ریاضی و پارامتر نظم
محاسبه‌ی اصلی سیستم بر اساس معادله میان‌میدانی Ising-type انجام می‌شود:

$$\theta(t+1) = \tanh\left(\frac{E(t) - E_c}{E_c} + \sum_{j \in \text{incoming}(i)} J_{ji} \theta_j(t - \tau_{ji})\right)$$

- **پارامتر نظم ($\theta$):** وضعیت داخلی نود در بازه $[-1, 1]$.
- **انرژی سیستم ($E$) و آستانه بحرانی ($E_c$):** تعیین‌کننده‌ی گذار فاز سیستم بین حالت متقارن و ناممتارن.
- **ماتریس کوپلینگ ($J_{ji}$):** وزن ارتباطی بین نودها در گراف‌های تنک.

## ۳. معماری جزیره‌ای (The Island Architecture)
برای جلوگیری از انباشت پیچیدگی و امکان توسعه ماژولار، اکوسیستم ONSOUR از الگوی **Island** استفاده می‌کند:
- هر جزیره (`Island`) یک ماژول مستقل است که می‌تواند وظیفه‌ای خاص (مانند پردازش جریان کار، رابط کاربری یا اتصال MCP) را انجام دهد.
- جزایر از طریق **Synaptic Hub** و پروتکل‌های استاندارد با یکدیگر تبادل اطلاعات می‌کنند.
- ارتباط میان هسته ران‌تایم Rust و ماژول‌های TypeScript از طریق واسط‌های `OnsourModule` و پل‌های WebAssembly مدیریت می‌شود.
