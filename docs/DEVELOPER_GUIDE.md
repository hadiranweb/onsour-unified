# راهنمای توسعه‌دهندگان اکوسیستم ONSOUR

## ۱. مقدمه
این مستند راهنمای جامعی برای توسعه‌دهندگانی است که قصد مشارکت در ساخت، توسعه و نگهداری مونو‌ریپوی اکوسیستم **ONSOUR** (`onsour-unified`) را دارند. این مونو‌ریپو بر پایه معماری ترکیبی **رجا (Rust)** و **تایپ‌اسکریپت (TypeScript)** بنا شده است تا سرعت پردازش بالا را در کنار انعطاف‌پذیری فرانت‌اند فراهم کند.

---

## ۲. پیش‌نیازهای سیستم
برای کار با این مونو‌ریپو، ابزارهای زیر باید روی سیستم شما نصب شده باشند:
- **Rust Toolchain**: نسخه پایدار (Stable) به همراه `cargo` (نصب از طریق [rustup.rs](https://rustup.rs/)).
- **Wasm-pack**: برای کامپایل کدهای Rust به WebAssembly (`cargo install wasm-pack`).
- **Node.js**: نسخه ۱۸ به بالا.
- **pnpm**: پکیج منیجر اصلی برای مدیریت فرانت‌اند (`npm install -g pnpm`).

---

## ۳. ساختار مونو‌ریپو
مونو‌ریپو به بخش‌های زیر تقسیم شده است:
- `theory/`: شامل مدل‌های ریاضی، مقالات تئوریک و کدهای مرجع پایتون (`Track A`).
- `backend/`: فضای کاری Rust شامل هسته بلادرنگ (`core/rts_core`) و سرویس‌های پلتفرم.
- `frontend/`: اپلیکیشن‌ها و بسته‌های مشترک فرانت‌اند (Remix / Next.js).
- `docs/`: مستندات معماری، گزارش‌های ران‌تایم و فایل‌های ارائه.
- `foundation.yaml`: مانیفست مرکزی برای ثبت ماژول‌ها و جزایر پلتفرم.

---

## ۴. دستورات ساخت و توسعه (Makefile)

برای تسهیل در فرآیند توسعه، تمامی دستورات کلیدی در `Makefile` ریشه مونو‌ریپو تجمیع شده‌اند:

### الف) راه‌اندازی اولیه محیط
```bash
make setup
```
این دستور وابستگی‌های Node.js را نصب کرده، هدف `wasm32-unknown-unknown` را به Rust اضافه می‌کند و ابزار `wasm-pack` را آماده می‌سازد.

### ب) کامپایل هسته Tanh-Brain به WASM
```bash
make build-core
```
این دستور هسته ریاضی را کامپایل کرده و پکیج خروجی را مستقیماً در مسیر `frontend/packages/rts-core-wasm` برای استفاده در فرانت‌اند قرار می‌دهد.

### ج) اجرای تست‌های یکپارچه
```bash
make test
```
این دستور تست‌های واحد و سیستم را در بخش Backend (شامل تست‌های هم‌ارزی عددی و مدیریت حافظه) اجرا می‌کند.

---

## ۵. استانداردهای مشارکت و کدنویسی
1. **قاعده Track C**: هرگونه تغییر در فرمول‌های ریاضی هسته باید ابتدا در `theory/python_reference` اعمال شده و با بردارهای تست (`test_vectors.json`) اعتبارسنجی شود.
2. **مدیریت حافظه**: ساختارهای داده در Rust باید با ویژگی‌های `#[repr(C)]` و حداقل سربار حافظه طراحی شوند (مطابق با تست‌های `memory_layout.rs`).
3. **ثبت ماژول جدید**: هر زمان که جزیره (Island) یا سرویس جدیدی به مونو‌ریپو اضافه می‌شود، باید مشخصات آن در فایل `foundation.yaml` ثبت گردد.
